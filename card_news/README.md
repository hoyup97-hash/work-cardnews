# 팀 카드뉴스 사이트 운영 매뉴얼

매일 아침 카드뉴스 HTML을 올리면, 1~2분 뒤 사이트에 자동으로 반영됩니다.
- 홈 화면 = 오늘의 카드뉴스. 사이트 주소로 들어가면 **가장 최근 카드뉴스가 바로** 보입니다.
- **스크롤을 내리면** 지난 카드뉴스가 날짜순으로 이어서 나옵니다.
- 날짜별 고정 주소도 있습니다: `.../cards/2026-11-06.html` (오른쪽 아래 공유 버튼은 지금 보고 있는 카드뉴스의 고정 주소를 보냄)

---

## 1. 매일 올리는 법 (담당자용)

1. 받은 HTML 파일 이름을 **오늘 날짜**로 바꾼다 → `2026-11-06.html`
2. GitHub 저장소에서 **`cards` 폴더**로 들어간다
3. 오른쪽 위 **Add file → Upload files** 클릭
4. 파일을 끌어다 놓는다
5. 아래 초록색 **Commit changes** 버튼 클릭
6. 1~2분 뒤 사이트 주소를 새로고침해서 확인 → 카톡 단톡방에 공유

> 반영이 됐는지는 저장소 위쪽 **Actions** 탭에서 볼 수 있습니다.
> 초록 체크(✓)면 성공, 빨간 X면 실패입니다.

## 2. 파일 이름 규칙

| 상황 | 파일 이름 |
|---|---|
| 기본 | `2026-11-06.html` |
| 같은 날 두 번째 | `2026-11-06-2.html` |
| 같은 날 세 번째 | `2026-11-06-3.html` |

- 규칙에 안 맞는 이름(예: `카드뉴스.html`)은 **목록에 나타나지 않습니다.**
  Actions 탭의 실행 결과에 노란 경고로 어떤 파일이 빠졌는지 표시됩니다.
- 카드뉴스 제목은 HTML 안의 `<title>` 내용이 그대로 목록에 쓰입니다.

## 3. 잘못 올렸을 때

- **내용을 고치려면**: 같은 이름으로 다시 업로드하면 덮어써집니다.
- **지우려면**: `cards` 폴더에서 해당 파일 클릭 → 오른쪽 위 `…` → **Delete file** → Commit changes
- **이전 버전으로 되돌리려면**: 파일 클릭 → **History**에서 예전 버전을 열어 내용을 복사해 다시 올립니다.

## 4. 주의사항

- 이 저장소와 사이트는 **공개**입니다. 주소를 아는 사람은 누구나 볼 수 있습니다.
- 한 번 커밋한 파일은 지워도 기록(History)에 남습니다.
  파일 이름, 커밋 메시지, 내용에 외부에 나가면 안 되는 정보를 넣지 마세요.
- 검색엔진에는 노출되지 않도록 설정되어 있습니다(noindex). 다만 비공개는 아닙니다.

## 5. 카카오톡 공유 버튼

홈 화면 오른쪽 아래와 날짜별 카드뉴스 화면 아래에 노란색 **공유** 버튼이 있습니다.

- **지금 (키 없음)**: 휴대폰에서는 공유 메뉴(카카오톡 포함)가 뜨고, PC에서는 링크가 복사됩니다.
- **카카오 키를 넣으면**: 버튼을 누르자마자 카카오톡 친구·단톡방 선택 창이 뜹니다.

카카오 키 넣는 법 (한 번만):
1. developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가 (이름 예: 팀 카드뉴스)
2. 앱 설정에서 **Web 플랫폼(사이트 도메인)** 에 사이트 주소의 도메인을 등록
   예: `https://hoyup97-hash.github.io` (조직으로 옮기면 `https://조직이름.github.io` 도 추가)
3. 앱 키 중 **JavaScript 키**를 복사해서 `config.json` 의 `kakao_js_key` 에 붙여넣고 커밋
   (JavaScript 키는 등록한 도메인에서만 동작하는 공개용 키라 저장소에 올려도 됩니다)

## 6. 폴더 구조

```
cards/                    ← 매일 카드뉴스 HTML을 올리는 곳 (담당자는 여기만 씀)
assets/                   ← 공유 버튼 스크립트(share.js), 대표 썸네일(og.png) 등 공통 파일
config.json               ← 카카오 키 등 설정
index.template.html       ← 홈 화면 틀 (카드뉴스는 자동으로 채워짐)
scripts/build.py          ← 목록을 자동으로 만드는 스크립트
.github/workflows/        ← 자동 배포 설정
```

`cards` 폴더 말고는 평소에 건드릴 일이 없습니다.

## 7. 처음 한 번만 하는 세팅 (관리자용)

1. GitHub에서 Organization 생성 (Free 플랜), Owner는 최소 2명
2. 이 저장소를 Organization 아래에 Public으로 생성하고 파일 업로드
3. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 변경
4. **Actions** 탭에서 첫 배포가 초록 체크로 끝나면 사이트 주소 확인
   → `https://조직이름.github.io/저장소이름/`
5. (선택) 대표 썸네일: `assets/og.png`를 올리고 `index.template.html`의 og:image 주석을 풀어 주소 입력
