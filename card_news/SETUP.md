# 새 담당자 세팅 (처음 한 번)

이 순서대로 하면 누구의 Claude에서든 카드뉴스를 만들고 올리고 예약할 수 있습니다.
카드뉴스를 **보기만** 하는 사람은 아무것도 할 필요 없습니다(사이트 링크만 열면 됨).

## 1. GitHub 계정과 저장소 권한
- GitHub 계정을 만듭니다(개인 계정, 무료).
- 관리자에게 아이디를 알려주고 `work-cardnews` 저장소 **쓰기 권한**을 받습니다.
  - 지금: 저장소 Settings → Collaborators 에서 초대 → 메일로 온 초대 수락
  - 팀 Organization으로 옮긴 뒤: Organization 멤버로 초대

## 2. Claude에 GitHub 연결
- claude.ai에서 GitHub 계정을 연결하고, Claude GitHub 앱의 저장소 접근에 `work-cardnews`를 허용합니다.
- github.com → Settings → Applications → Claude 에서 저장소 접근이 **Only select repositories → work-cardnews** 로 돼 있는지 확인합니다(다른 저장소까지 열어 둘 필요 없음).
- Organization으로 옮긴 뒤에는 Organization 관리자가 Claude 앱 설치를 승인해야 할 수 있습니다.

## 3. 스킬 두 개 추가 (claude.ai 계정)
- **fubon-news-newspaper**: 카드 내용(기사 고르기·3줄 요약)을 정하는 스킬. 만든 동료에게 공유받아 추가합니다.
- **cardnews-site**: 사이트에 올리기·예약·확인·수정을 맡는 스킬. 이 저장소의 `card_news/cardnews-site/SKILL.md` 를 받아 스킬로 추가합니다(또는 관리자에게 공유받기).

## 4. 동작 확인
- Claude에서 웹 검색이 켜져 있는지 확인합니다.
- 새 채팅에 **"카드뉴스 시험 모드로 하나 만들어줘"** 라고 보냅니다.
  - HTML 파일이 오면 세팅 완료입니다(사이트에는 올라가지 않음).
  - 막히면 Claude가 어디서 막혔는지 알려줍니다. 대부분 1~3번 중 빠진 것입니다.

## 5. 매일 자동 발행을 맡는 경우
- **"평일 아침 7시 30분에 카드뉴스 자동 발행 예약해줘"** 라고 보냅니다.
- 예약 작업 설정에서 **자동 승인**을 켜 둡니다. 꺼져 있으면 아무도 없는 아침에 승인 대기로 멈춥니다.
- **예약은 담당자 한 명만** 걸어 둡니다. 두 사람이 같이 걸면 같은 날 카드가 두 번 올라갑니다.
- 결과는 예약 작업의 실행 기록에서 확인하고, 단톡방 공유는 사람이 합니다.

## 자주 쓰는 말

|---|---|
